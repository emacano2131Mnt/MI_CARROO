## Criterio de estado

- **Probado correctamente:** hay una prueba automatizada ejecutada que cubre la condición indicada.
- **Implementado, pendiente de pruebas:** el código cubre las condiciones descritas, pero no hay prueba automatizada o manual documentada suficiente para este requisito.
- **Parcialmente implementado:** hay una parte demostrable, pero falta una o más condiciones explícitas.
- **Pendiente:** no se encontró implementación de la capacidad requerida.
- **No verificable con la evidencia disponible:** exige mediciones, dispositivos, auditorías o una función condicional que no están disponibles en el repositorio.

### Hallazgos transversales y límites

1. **Desviación tecnológica del documento:** el DOCX define un producto Android nativo desarrollado en Kotlin. El repositorio real es React Native + Expo SDK 57 + Expo Router + TypeScript (consistente con `AGENTS.md`). La lógica descrita sí puede evaluarse, pero la plataforma/tecnología objetivo del documento no coincide.
2. **Persistencia:** `src/database/database.ts` implementa cuatro tablas (`vehicles`, `readings`, `activities`, `services`). No hay tablas de repuestos o documentos. El diseño existente usa SQLite local, sin sincronización.
3. **Pruebas actuales:** `npm test` ejecutado tras las últimas mejoras: 23/23 pasan, con reglas, operaciones de servicios y una migración aditiva de vehículos probadas con SQLite en memoria. Node muestra una advertencia no fatal `MODULE_TYPELESS_PACKAGE_JSON`. `npx tsc --noEmit`, `npm run lint` y `npx expo-doctor` pasaron en la entrega de octubre de 2026. Estas comprobaciones no sustituyen las pruebas de interfaz o dispositivo.
4. **Evidencia de documentación previa:** `docs/GUIA_DEL_PROYECTO.md` y `docs/AVANCE.md` describen las áreas existentes; se añadió a `docs/AVANCE.md` una actualización de esta entrega. No se verificó manualmente en dispositivo.
5. **No ejecutado en esta auditoría:** no se probó Expo Go/emulador, persistencia después de reinicio, confirmaciones de la interfaz, accesibilidad en lector de pantalla, tamaños Android, rendimiento con 1.000 registros, permisos del manifiesto instalado, red/HTTPS, restauración ni flujos de funciones ausentes. No existe sistema de notificaciones que deba cancelarse al borrar actividad. Los estados no afirman que esas pruebas hayan pasado.
